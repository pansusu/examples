# ADK Software Bug Assistant (Java)

Java translation of `adksamples/software-bug-assistant` using ReactAgent with tools.

- Agent: `software_assistant`
- Tools: get_current_date, search_tool, langchain_tool, toolbox_tools, mcp_tools

Run:
```bash
mvn -q -DskipTests package
java -jar target/adk-software-bug-assistant-0.0.1-SNAPSHOT.jar
```
