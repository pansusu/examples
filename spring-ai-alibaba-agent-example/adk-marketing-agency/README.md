# ADK Marketing Agency (Java)

Java translation of `adksamples/marketing-agency` using Agent Tool pattern.

- Coordinator: `marketing_coordinator`
- Tools: domain_create_agent, website_create_agent, marketing_create_agent, logo_create_agent

Run:
```bash
mvn -q -DskipTests package
java -jar target/adk-marketing-agency-0.0.1-SNAPSHOT.jar
```
